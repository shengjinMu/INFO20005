What is PETHAUS?

PETHAUS is a website that sells clothing and accessories. It is designed for dogs and people who care about them. The goal was to make shopping feel clean, modern and easy.

This website was part of a university course called INFO20005 Web Design at the University of Melbourne. The project had three stages:

  • analysing a poorly designed website
  • creating a prototype
  • building the final version with HTML, CSS and JavaScript

Assignment 1. Critique

The first part was to look at a website that was not well designed. I found problems like:

  • hard to understand navigation
  • layout
  • confusing user flow

This helped me see how design choices affect how people use a website. I used this to make PETHAUS clearer, easier to use and more polished.

Assignment 2. Prototype

I made a prototype of PETHAUS using Figma. I created all the pages, including:

  • homepage
  • product pages
  • cart
  • checkout
  • confirmed page

The prototype helped me plan the website's look, including layout, fonts, colors and user flow. It was a guide for building the website.

Assignment 3. Implementation

The last part was to turn the prototype into a website using HTML, CSS and JavaScript.

The biggest changes from the prototype to the final build include:

  • a cart that saves across pages using localStorage
  • three payment methods with an expandable accordion (Apple Pay, Credit Card, PayPal)
  • checkout form validation before payment can proceed
  • a live search that filters products as you type
  • a responsive layout that works on both mobile and desktop

Overall PETHAUS shows my process of designing and building a website. I started by finding problems with another website then made a prototype and finally built an usable website.
