What is PETHAUS?

PETHAUS is a pet clothing and accessories website designed for dogs and the people who care about them. The aim of the project was to create a shopping experience that feels clean, modern, and easy to use, while still showing a strong visual identity.

This website was developed as part of the INFO20005 Web Design course at the University of Melbourne. Across the semester, the project moved through three main stages: analysing a poorly designed website, creating a high-fidelity prototype, and then building the final version with HTML, CSS, and JavaScript.

Assignment 1 — Critique

The first stage focused on analysing an existing website with poor design. I looked at issues such as unclear navigation, weak visual hierarchy, inconsistent layout, and confusing user flow.

This helped me understand what makes a website difficult to use. These findings then influenced the direction of PETHAUS, especially the focus on clarity, simple interactions, and a more polished visual style.

Assignment 2 — Prototype

In the second stage, I created a Figma prototype for the PETHAUS website. This included key pages such as the homepage, product pages, cart, checkout, login, and register screens.

The prototype helped me test the layout, typography, colour palette, and overall user journey before moving into code. It also acted as a clear design guide when building the final website.

Assignment 3 — Implementation

The final stage was turning the Figma prototype into a working website using vanilla HTML, CSS, and JavaScript.

The website includes features such as a persistent cart using localStorage, product image sliders, price filtering and sorting, login and register pages, and a responsive layout for different screen sizes.

Overall, PETHAUS shows the full process from design critique to prototype to implementation. It started as a response to poor web design, and gradually developed into a more complete and usable e-commerce website.
